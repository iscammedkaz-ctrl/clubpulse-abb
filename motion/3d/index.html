Bézier cubique 3D

Courbes 2D · Lissage

En CSS, une courbe de Bézier est 2D : le temps sur X, la progression sur Y. Ici la même formule avance un point dans l’espace (x, y, z) — trajectoire de logo, caméra, ou pub sponsor. Faites glisser pour orbiter.

B(t) = (1−t)³P₀ + 3(1−t)²t P₁ + 3(1−t)t² P₂ + t³ P₃  ·  t ∈ [0,1]
